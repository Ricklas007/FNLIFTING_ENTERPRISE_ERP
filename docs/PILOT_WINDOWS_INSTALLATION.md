# Instalação piloto Windows

1. Execute `C:\Projetos\FNLIFTING_ENTERPRISE_ERP\release\FNLIFTING-ENTERPRISE-ERP-Setup-0.12.2.exe`.
2. Escolha instalação por utilizador para evitar elevação; a aplicação guarda dados em `app.getPath("userData")`.
3. Abra o atalho e confirme splash, backend, login e dashboard.
4. Não copie `.env`, bancos, backups ou `.venv` para `Program Files`.

O smoke automatizado validou três arranques do `win-unpacked`. A instalação interativa desta execução não foi realizada.
